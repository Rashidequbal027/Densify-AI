# Densify AI - Smart Crowd Monitoring & Estimation Platform

## 📌 Overview
Densify AI is a real-time crowd monitoring system that uses YOLOv8 and OpenCV to detect and count people in video streams.

## 🚀 Features
- Real-time people detection
- Crowd counting
- Density classification (Low / Medium / High)
- Web dashboard using Flask

## 🛠 Tech Stack
- Python
- OpenCV
- YOLOv8
- Flask

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000/

## 📊 Future Enhancements
- Heatmaps
- Multi-camera system
- Alerts & notifications

## 📁 Dataset
COCO dataset (used by YOLO)
